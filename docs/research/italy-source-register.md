# Italy — source register

Every source used for the Italy pages, verified on 2026-07-26 and independently re-checked (no
factual errors; every primary source re-fetched verbatim).

## Access note

The Senate's English Constitution PDF was bot-walled, so the Constitution is cited from the
**Constitutional Court's own official English PDF**. Law 121/1981 is the official government PDF.
The National Guarantor (detention oversight) was reached only through a search, so it is flagged.
